CinéScope : Architecture & Spécifications Projet

Documentation complète de conception assistée par IA, de l'architecture logicielle et du protocole de déploiement automatique sur GitHub Pages.

1. Objectifs & Cahier des Charges

Développer et déployer une application d'exploration cinématographique (« CinéScope ») réalisée avec des outils d'intelligence artificielle, répondant aux contraintes ergonomiques strictes :

  • Thème Clarté Totale (Light Mode) : Palette lumineuse (blanc pur, ardoise 50/100, bordures subtiles), éliminant les fonds sombres génériques.
  • Plein Écran & Fluide : Disposition responsive à 100% de la largeur, optimisée pour moniteurs desktop et smartphones.
  • Zéro Émoji & Iconographie Vectorielle : Composants SVG sur mesure pour une identité professionnelle sans look généré par IA.
  • Données Réelles : Sélection cinématographique de référence et profil réel de Charf Eddine (Mila, Algérie).

2. Stack Technologique

Architecture Déclarative Composants réactifs et gestion d'état
Bundler Vite & Standalone Compatibilité GitHub Pages & ouverture locale directe
CSS3 Vanilla Pure Design System sur mesure sans framework lourd
YouTube IFrame API Intégration fluide de bandes-annonces HD 16:9
LocalStorage Sync Persistance locale de la Watchlist
GitHub Pages Ready Hébergement mondial sans erreur 404
